# 📱 Social Media Content Planner

A practical social media planning project designed to organize content ideas, publishing schedules, target audiences, and performance tracking.

## 🎯 Project Goal

The goal of this project is to create a simple and organized system for planning social media content across different platforms.

## ✨ Features

- 📅 Content calendar
- 💡 Content idea management
- 🎯 Target audience planning
- 📱 Social media platform selection
- 📝 Caption and content planning
- 📊 Performance tracking
- 🔄 Content status tracking
